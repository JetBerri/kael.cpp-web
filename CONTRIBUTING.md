# Contributing

This site grows through contributions. Fix a sentence, add an exercise to a chapter, or write a concept article.

The complete guide is [content/contributing.md](content/contributing.md), published at https://kaelcpp.dev/contributing/. It covers the page format, links, callouts, math, diagrams and the writing style.

## Quick path

1. Install [Zola](https://www.getzola.org/) 0.23 and run `zola serve`.
2. Edit or add a Markdown file under `content/`.
3. Run `zola check`.
4. Open a pull request with a Conventional Commit title, for example `docs(concepts): add quantization article`.

Use one pull request per topic. Report problems in the library itself in the [kael.cpp repository](https://github.com/JetBerri/kael.cpp/issues).
