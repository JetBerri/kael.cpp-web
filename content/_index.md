## introduction

kael is a deep learning framework written from zero in modern C++. It has tensors with shapes and strides, views that share memory, a loop engine with broadcasting and type promotion, reverse-mode autograd, neural network modules and optimizers, a multithreaded CPU backend, a CUDA backend, Python bindings, and a GPT-2 that loads real weights and generates text.

Every layer is implemented from scratch, with no wrappers around another framework. Each one is tested against PyTorch and explained in a book that rebuilds it step by step.

```cpp
#include <iostream>

#include "kael/kael.h"

int main() {
    kael::Tensor x = kael::randn({64, 784});
    kael::Tensor w = kael::randn({784, 10}).requires_grad_();

    kael::Tensor loss = kael::relu(kael::matmul(x, w)).sum();
    loss.backward();

    std::cout << *w.grad() << "\n";   // dloss/dw, shape=[784, 10]
}
```

## results

Measured on an Apple M5 Pro (15 cores) for the CPU and on an NVIDIA Tesla T4 for the GPU. Every number comes from a command in the repository.

| Workload | CPU, Apple M5 Pro | GPU, NVIDIA T4 |
|----------|-------------------|----------------|
| MNIST MLP, 5 epochs | 97.42% test accuracy, 0.62 s per epoch | 97.18% test accuracy, 1.52 s per epoch |
| `matmul`, `f32` | 557 GFLOP/s at 1024 x 1024 | 427 GFLOP/s at 2048 x 2048 |
| GPT-2 small, text generation | 15 tokens/s | 14 tokens/s |

Correctness is checked against PyTorch: 783 golden cases over 67 operations, generated by PyTorch and replayed by the C++ tests, plus 30 Python tests that compare kael with PyTorch and with the Hugging Face GPT-2 logits.

The GPU numbers are not higher than the CPU numbers. The MNIST model is too small to keep a GPU busy, and the CUDA kernels favor clarity over speed, as [chapter 09](@/book/09-cuda-backend.md) explains.

## motivation

- Why does `reshape` sometimes copy and sometimes not?
- How does `a + b` work when `a` is `[3, 1]` and `b` is `[4]`?
- What does `loss.backward()` actually walk, and in which order?
- Why is a naive matrix multiply 300 times slower than a tuned one on the same CPU?
- What happens between a `.safetensors` file on disk and a sentence of generated text?

Frameworks such as PyTorch answer these questions in millions of lines of code. kael answers them in a codebase small enough to read in a few weeks, with every decision written down.

## quick start

kael needs CMake 3.24 or newer and a C++20 compiler.

```bash
git clone https://github.com/JetBerri/kael.cpp
cd kael.cpp
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Then start with the [overview](@/book/00-overview.md).
